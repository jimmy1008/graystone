# 04 需求與消耗

> **動態化聲明**：本文數值為初始參數（正本 `data/params.yaml` needs 節）。「25 成人/3 少年/2 老人」是開局快照——人口會生老病死婚遷（docs/09.B），需求總量隨人口結構逐日重算。

## 食物（每日，夜間段結算）

| 人口類型 | 日需求（食物單位） |
|---|---:|
| 成人（25 人） | 1.0 |
| 少年（3 人） | 0.8 |
| 老人（2 人） | 0.7 |

- **全村日需求 = 25×1.0 + 3×0.8 + 2×0.7 = 28.8 食物單位**
- 換算：穀物 1 份 = 1.0 單位；肉/鹽漬肉 1 份 = **1.5 單位**
- 進食順序：戶內先吃易腐的（肉 → 穀物 → 鹽漬肉留到冬天），由清晨段的戶內分配決定
- 基線飲食結構：獵戶日產肉 6 份（≈9 單位）由全村消化，其餘 ~19.8 單位吃穀物 → **全村日耗穀物 ≈ 20 份**

## 飢餓與死亡

| 狀態 | 效果 |
|---|---|
| 當日吃不到需求的 50% | 體力 −15 |
| 連續 2 天缺糧 | 體力上限 −10/天（累積） |
| 連續 7 天嚴重缺糧 | 健康開始 −5/天 |
| 健康 < 30 | 無法勞動 |
| 健康 = 0 | **死亡**（允許發生；死亡=重大事件，必落盤，遺產按戶內繼承） |

## 柴火（冬季，第 271~360 天）

- 每戶每日 2 捆（不分戶內人數——爐子是戶的，這也是「戶」作為單位的意義）
- **冬季全村需求 = 12 戶 × 2 × 90 = 2,160 捆**
- 缺柴的戶：戶內全員健康 −2/天；暴雪事件期間 −5/天

## 衣物

- 每人每年 1 匹布（商隊進口，8G）——秋收後結算，各戶依現金購買
- 連續 2 年未換衣：健康上限 −5（低優先，主要是給商人的穩定需求流）

## 麥酒與社交（非必需消費）

- 傍晚去酒館者消費 1~2 杯（2G/杯）
- 效果：心情 +10、當晚同席者關係 +1；心情影響隔日體力恢復（心情 >70：+5 恢復）
- **心情**：0~100，基準 50。吃肉 +2、缺糧 −10、家人受傷 −15、關係事件 ±（docs/07）
- 心情 <20 持續 14 天 → 觸發「消沉」：產出 ×0.7（純規則版對「精神狀態」的最簡代理）

## 體力與恢復（夜間段結算）

- 工作日：體力 −20（危險工作 −25）
- 夜間恢復：+25（吃飽）/ +10（缺糧）/ 心情加成 +5
- 受傷/生病：按 docs/03 醫療規則恢復

## 消耗相關的調參旋鈕

- 肉的滿足度（1.5×）：決定獵戶在食物體系的權重
- 冬季柴火 2 捆/戶/日：直接決定冬季伐木勞動力需求
- 缺糧懲罰斜率：決定「餓幾天會死人」——太陡則單一歉收就滅村，太緩則糧食壓力無感
