# 05 經濟與物價

> **動態化聲明（docs/09 優先）**：基準價只是第 0 天的錨，此後「基準」= 近 90 日成交均價（滾動錨），物價水平允許永久漂移。稅率、守衛薪資、商隊收購上限都是可變參數（[P2] 標記者未來由村長等世界內決策修改）。本文數值正本在 `data/params.yaml`。

## 貨幣總量：開局 3,000G（守恆式審計，非固定常數）

> 村內任何交易只是金幣換手。**唯一的進出閥門是商隊**——跨境金流單獨記帳，審計公式：`村內總額 = 3,000 + Σ(商隊淨流入)`。總量會隨貿易順逆差變動，審計只驗守恆不鎖總量。

## 動態調價

`當前價 = 基準價 × clamp(近30日需求量 / 近30日供給量, 0.5, 3.0)`

兩條補充世界規則（2026-08-10，源自「開局物價跳崖」的教訓）：
- **開局物價自洽**：村產品（穀/肉/柴/酒）的開局價由開局世界狀態（庫存/人口/產能）用同一套供需公式推導——基準價只提供「價值尺度」（肉為何比穀貴），價位從第 0 天就是湧現的，不存在「設計價 vs 實況」的落差。外來品（鹽/布/種糧/工具）由磐石鎮定價，維持基準價。
- **調價黏性**：商人每週調價上限 ±15%（params `price_stickiness`）——劇烈供需變化以「連續數週的方向性移動」呈現，不會一夜腰斬。週變幅 ≥12% 即落盤為物價事件。

- 重估頻率：商人與酒館每 **7 天**重估一次；其他交易（戶際）直接用當前市價
- 供需雙方都缺數據時（開局）用基準價
- clamp 上限 3.0 是防爆炸的世界法則；若模擬中價格長期貼著上限，代表該資源的生產規則失衡——這是 M2 要抓的訊號

## 固定金流

| 金流 | 頻率 | 金額 | 方向 |
|---|---|---|---|
| 守衛薪資 | 每 30 天 | 20G ×2 人 | 村庫 → 守衛戶 |
| 收成稅 | 每年第 256 天 | 各戶收成 5%（實物穀物） | 各戶 → 村庫 |
| 村庫售糧 | 不定 | 市價 | 村庫 → 缺糧戶（青黃不接時的平準機制） |

### 村庫收支試算（年）

- 支出：守衛薪資 480G
- 收入：稅糧 ≈ 9,750 × 5% ≈ 488 穀物，按市價（青黃不接時 >1G）賣出 ≈ 500G+
- **結論：村庫大致自持，但一次歉收就會赤字**——這是設計上故意留的脆弱點，村長（Phase 2 的 LLM NPC）的核心決策題

## 商隊（每 30 天，冬季 30% 延誤）

| 方向 | 品項 | 商隊出價 |
|---|---|---|
| 收購（金幣流入村莊） | 皮毛 4G、鐵礦 2G、工具 12G | 按村內市價 ±10% |
| 出售（金幣流出村莊） | 鹽 5G、布 8G、種糧 2G | 固定價 |
| 交易對口 | 主要走雜貨商（賺價差 10~15%），各戶也可直接交易 | |

### 村莊貿易平衡試算（年）

- 出口：皮毛 ~140 張(560G) + 鐵礦盈餘 ~1,800 塊(3,600G，礦工主要收入) + 工具偶售 ≈ **~4,300G 流入**
- 進口：鹽 ~40 包(200G) + 布 30 匹(240G) + 種糧備補 ≈ **~500G 流出**
- 帳面上大幅順差——**這不合理，M2 調參重點**：磐石鎮對鐵礦的收購量必須設上限（例如商隊每次最多收 150 塊），否則礦工變首富、貨幣灌入通膨。真實約束是「商隊運力有限」。初版設定：**商隊單次收購上限 150 鐵礦 / 30 皮毛 / 5 工具**。

## 以物易物與賒欠

- 任何交易可用實物按市價折算（貧窮村莊的常態）
- **賒欠（人情帳）**：關係 ≥ +30 的戶之間可賒欠，記入 `debts`；賒欠未還會在關係值上慢性扣分（−1/30天）
- 賒欠是純規則版就要有的機制——它是日後大部分「恩怨劇情」的燃料

## 經濟不變量（M2 引擎驗收用）

1. 村內金幣總量 = 3,000 + 商隊淨流入（每 30 天審計）
2. 任何戶金錢不得為負（賒欠走 debts 表，不走負數）
3. 物價不得長期（>60 天）貼 clamp 上下限
4. 基尼係數警戒：全村財富基尼 > 0.6 時發警告（不是 bug，是值得看的社會現象）
