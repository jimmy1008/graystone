# 08 Canon 與資料分層（FACT / KNOWN / BELIEF / HYPOTHESIS / UNKNOWN）

> 這是整個架構最重要的一份文件。它存在的理由：**LLM 幻覺不可避免，但幻覺永遠不能污染世界真相。** 純規則版（本階段）只會用到 FACT 與 known_by；其餘層次現在定義好結構，Phase 2 直接使用。

## 五層資料定義

| 層 | 定義 | 誰能寫入 | 可以錯嗎 |
|---|---|---|---|
| **FACT** | 世界真相（Canon）。事件真的發生過、人真的存在、物品真的在誰手上 | 只有引擎（生產/交易/事件結算） | 不可能錯——它就是定義 |
| **KNOWN** | 某 NPC 確知的事 = FACT 中 `known_by` 包含他的子集 | 引擎（在場/被告知時自動寫入） | 不會錯，但**不完整** |
| **BELIEF** | 某 NPC 相信的事 | Phase 2：LLM 提案；純規則版：canon_seed 預埋 | **可以錯**——這是劇情的來源，不是 bug |
| **HYPOTHESIS** | 某 NPC 的猜測（自己也不確定） | 同上 | 當然可以錯 |
| **UNKNOWN** | 標記「此問題無人知道答案」 | 設計者/引擎 | — |

### 鐵律

1. **LLM（Phase 2）只能寫 BELIEF / HYPOTHESIS，永遠不能寫 FACT。**
2. BELIEF 升格為 FACT 只有一條路：LLM 提案 → 引擎驗證（Registry 查得到人？物品存在？當事人真的在場？）→ 作為新事件落盤。驗證不過 → 只留在該 NPC 的 BELIEF 裡（他可以繼續錯下去）。
3. **NPC 永不能憑空創造人**：對話/決策中引用的任何人名必須在 `character_registry` 查得到，查不到 → 引擎退回（"你不認識叫這個名字的人"）。未來若劇情需要新人物（如商隊成員），走 `CreateCharacter` 流程：需要出生/來歷、時間、地點、與現有網絡的關係，由引擎建 ID 後才存在。
4. 死亡的人保留在 registry（標記 dead）——死人可以被談論，不能行動。
5. **隱藏 Canon（機緣）**：世界允許存在 `discovered=false` 的 FACT——已成立但無人知曉的事實（遺物、秘密、被遺忘的過往）。它們由 LLM 埋設者提案、經七關驗證後埋入（詳見 docs/10），埋設後即為 Canon 不可改動；發現只是揭示，不是創造。這是「小概率奇遇」與「先射箭後畫靶」之間的防火牆。

## character_registry（人物唯一真相）

每個曾存在的人一條記錄：`id, 姓名, 生年, 卒年(nullable), 戶, 職業史, 狀態(alive/dead/departed)`。
**開局僅 30 人**——沒有預埋的歷史人物。此後的新記錄只能來自：出生、遷入、死亡標記（docs/09.B）。

## 事件因果圖（Canon 的骨架）

- 格式見 docs/07。`caused_by` 邊 + `known_by` 清單構成「世界史」
- **開局事件圖為空**。世界史從第 1 天開始由模擬自己寫

## 零預埋劇本原則（用戶裁決，2026-08-09）

**世界開局不埋任何劇情線。** 沒有舊怨、沒有秘密、沒有暗線、沒有彩蛋。開局唯一的「歷史」是結構性人口事實（誰是誰的家人/同業/鄰居），不附帶敘事解釋。

所有故事必須由模擬運行中**各人物的關係、行為、話語**湧現：

| 故事元素 | 湧現路徑 |
|---|---|
| 恩怨/情誼 | 模擬中真實發生並落盤的糾紛/互助/借貸/交易事件（docs/06） |
| 秘密 | `known_by` 傳播的自然不均——有人在場、有人不在場、有人被告知、有人沒有 |
| 誤會 | Phase 2 LLM 在資訊不全下寫入的 BELIEF（引擎保證永不污染 FACT）；純規則版由「部分知情」自然構成 |
| 奇遇 | docs/10 機緣系統——觸發時定奪，前因必須引用世界已累積的真實歷史 |

這比預埋暗線更嚴格，也更誠實：**如果跑一年後世界裡沒有長出任何故事，那是引擎與規則的失敗，要修的是系統，不是補寫劇本。**（「世界能不能自己產生歷史」正是整個專案要驗證的命題——預埋劇本等於在考卷上先抄好答案。）

M4 的 LLM 驗收也因此改變：不再是「LLM 能否正確扮演預設恩怨」，而是「LLM 面對模擬自己長出來的事件史，能否做出前後一致、只依 KNOWN 發言的行為」——這更接近真實驗證。

## 資料表總表（對應 schema.sql）

| 表 | 內容 | 本階段 |
|---|---|---|
| character_registry | 人物唯一真相 | ✅ 種子資料 |
| households | 戶（財產單位） | ✅ |
| npcs | NPC 動態狀態（體力/健康/心情/位置） | ✅ 初始值 |
| items / item_registry | 散裝庫存 + 個別物品 | ✅ |
| stocks | 各戶/機構散裝資源庫存 | ✅ |
| prices | 當前價與歷史 | ✅ 基準價 |
| transactions | 交易流水（審計用，可定期壓縮） | 結構 |
| debts | 賒欠/人情帳 | 結構 |
| relationships | 關係值 | ✅ 結構性預設（同戶/同業/鄰居），零覆寫 |
| events | 事件因果圖（含 known_by） | 開局為空 |
| beliefs | NPC 的 BELIEF/HYPOTHESIS | 開局為空 |
| world_state | 日期/季節/進行中事件/村庫 | ✅ 初始值 |
