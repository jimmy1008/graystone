# 09 動態系統 — 天氣 / 人口 / 發展 / 經濟 / 人物（一切皆湧現，不寫死）

> **本文件優先級高於 01~07 中的固定數值表。** 那些表格是「期望值示意＋開局種子」；引擎實際運行時，天氣、產量、物價、人口、村莊樣貌全部由本文件的動態系統驅動。**所有參數的正本在 `data/params.yaml`，引擎程式碼中不得出現任何魔法數字。**

## 設計原則

1. **數值分兩種**：`世界法則`（品級上限、守恆律——不可變）與 `參數`（其他一切——集中在 params.yaml，可調、可被世界內事件改變）。
2. **能湧現的不用擲骰**：歉收不是 15% 的骰子，是整個夏天的天氣積分算出來的；商隊延誤不是機率表，是道路天氣的直接後果。01/07 的機率表只保留「無法還原成機制的殘餘隨機性」（狼群、疫病源）。
3. **沒有東西是永恆的**：礦脈會枯竭、地力會下降、老人會死、年輕人會離開、村莊可能擴張也可能荒廢。30 人 12 戶只是第 0 天的快照。

## A. 天氣系統（取代 01 的固定季節係數）

每日天氣由**季節性馬可夫鏈**生成：

- 狀態：`晴 / 陰 / 雨 / 雪 / 暴風`
- 持續性：60% 沿續昨日，否則按當季分布抽新狀態（分布矩陣在 params.yaml，四季各一組）
- 每日同時生成**溫度帶**（暖/涼/寒/酷寒，季節基準 ± 隨機漂移）

### 天氣 → 世界的傳導（全部是機制，不是骰子）

| 下游 | 機制 |
|---|---|
| 農作 | 生長季（春播~秋收）逐日累計**生長積分**：晴+2 雨+1 陰+1 寒−1 暴風−3。收成係數 = f(積分/滿分)，範圍 0.5~1.3——「豐年/歉收」由此湧現，01 的年擲一次作廢 |
| 戶外工作 | 雨：效率 ×0.8；暴風/酷寒：戶外停工（農/獵/礦/伐木） |
| 商隊 | 抵達前 5 日的道路天氣：每個暴風/大雪日 +3 天延誤——冬季延誤由此湧現 |
| 柴火 | 酷寒日消耗 ×1.5（取代固定的冬季常數） |
| 狼群 | 冬季嚴寒指數（酷寒日累計）越高，狼群下山壓力越大（修正殘餘隨機性的權重） |
| 疫病 | 春季濕度指數（雨日累計）修正疫病基礎機率 |

## B. 人口動態（30 人只是第 0 天）

### 老化與死亡
- 年末全員 +1 歲
- 年度自然死亡率曲線（params）：成年基準 0.3%，55 歲後隨年齡陡升（60→2%、70→6%、80→15%）；由當年平均健康/營養修正
- 飢餓/受傷/疫病死亡照 04 規則隨時發生
- 死亡 = 重大事件：繼承（戶內）、職業空缺（docs/06 繼承規則）、關係網重組、葬禮（神龕事件）

### 婚配與生育
- 未婚成年（18~40）之間關係 ≥ +40 且非同戶血親 → 每年婚配判定（機率 params）
- 成婚 → 組新戶（觸發**建屋計畫**，見 C）或併入一方戶
- 已婚且妻齡 18~42 → 年度生育判定（基準 25%，糧食安全/心情修正）；懷孕 270 天 → **出生 = CreateCharacter**（嬰兒，非勞動；14 歲轉半勞動、16 歲全勞動、跟戶學技能）

### 遷出與遷入（村莊與外界的人口閥門）
- **遷出**：18~35 歲、連續 90 天心情 <30 或收入長期墊底 → 「去磐石鎮闖蕩」判定（status: departed，registry 保留，可能帶著故事回來——Phase 2 素材）
- **遷入**：村莊**繁榮指數**（見 D）連續高檔 → 流浪者/工匠/逃難者抵達判定，走 `CreateCharacter` 流程（模板：來歷/技能/初始關係=全 0/低信任），**這是新人物進入世界的唯一合法途徑之一**（另一條是出生）——LLM 永遠不能憑空造人，但世界機制可以
- 商隊成員固定為「過境人物」（不入常駐 registry，除非發生留下事件）

### 人口對世界的反饋
人口升 → 糧食需求升、勞動力升、新戶建屋需求；人口降 → 田地照料不足、職業斷層（鐵匠死了沒學徒=全村工具劣化）——**不做任何「自動平衡」，讓後果真實發生**。

## C. 村莊發展（樣貌可變）

| 系統 | 機制 |
|---|---|
| **地力** | 每塊田 fertility 0.6~1.3（開局 ~1.0）。連年耕作 −0.05/年；休耕一年 +0.10。收成 = 產量公式 × fertility——「要不要輪耕」成為真實決策（Phase 2 村長議題） |
| **開墾新田** | 條件：連續兩年糧食盈餘 + 冬季閒置勞力 ≥ 200 人日 + 村庫出資 50G → 新田 fertility 0.7 起。田地也可荒廢（連續兩年無人耕 → 移出可用清單） |
| **礦脈枯竭** | 礦脈分層：**淺層（技術可及）僅 ~9,000 塊**，深層 ~30,000+ 塊存在但本村技術挖不到（無支護/排水/精煉——docs/03）。累計開採每 1,000 塊，日產 ×0.95（淺層越挖越貧）。淺層見底（約 5 年）→ 礦工失業鏈 → 轉職/遷出——**這是設計好的第一場結構性危機**。低機率「發現新露頭」事件（勘探=冬季勞動投入可提升機率）只延緩不逆轉；真正的出路是深層解鎖（需外來技術/設備投資，遠期發展鉤子） |
| **珍稀發現** | 採礦 0.5%/人日挖到貴重物（銀礦石/寶石原石/古物，docs/03）。發現物是**中性物件**（零預埋劇本）；走「事件產物」路徑不違反物品守恆，後續由人物行為湧現 |
| **建屋** | 新戶成立觸發：木柴 200 + 勞力 100 人日 + 30G → 新民居入 locations。無力建屋 → 併戶擠住（心情懲罰）——貧窮的真實樣子 |
| **技能成長** | 每 300 有效工作日技能 +1，上限=天資（每人建立時抽 1~5，params 分布）。學徒制：跟隨 Lv≥3 者工作，成長速度 ×2 |
| **設施** | 糧倉容量有限（params，2,500）；超儲 → 損耗率上升 → 「擴建糧倉」成為村莊決策。酒館/鐵匠鋪同理可擴可衰 |

## D. 經濟動態（基準價只是第 0 天的錨）

- `data/prices.yaml` 的 base_prices **只在開局第一次交易前有效**；此後「基準」= 該品項近 90 日成交均價（滾動錨），動態調價公式作用在滾動錨上——物價水平可以永久漂移（通縮/通膨都允許發生，審計只管守恆不管價格）
- 貨幣總量**不是常數**：商隊淨流入/流出改變它（守恆式：村內總額 = 3,000 + Σ淨流入）。防通膨閥門（商隊收購上限）本身也是參數，且可被「磐石鎮景氣」事件修改
- 稅率（5%）、守衛薪資（20G）是**村長可改的參數**（純規則版不改；Phase 2 成為 LLM 決策項）
- 職業收入結構完全湧現：若模擬中「所有人都跑去採礦」，那是參數失衡的**訊號**，用供需（礦價下跌）去自然糾正，而不是硬性禁止轉職

## E. 人物動態（性格與關係也不是常數）

- **性格漂移**：重大人生事件觸發標籤變動判定（params 機率）——喪偶 → 孤僻傾向；橫財 → 貪心/慷慨分歧（既有標籤決定方向）；長期貧困 → 吝嗇傾向。漂移是低頻的（一生 0~3 次），但存在
- **關係自然衰減**：90 天無互動的非親屬關係向 0 緩慢回歸（±1/90天）——恩情會淡，仇恨也會。例外：被重大落盤事件錨定的關係（死亡、背叛級糾紛等，模擬中產生）不衰減
- **新人物的性格**：出生/遷入時從 params 的標籤分布抽取，父母標籤有遺傳權重
- 30 人名冊（npcs.yaml）是**種子資料**：跑十年後的灰石村名冊應該跟開局長得不一樣——有人死了、有人生了、有人走了、有人變了

## 殘餘隨機性清單（真正保留骰子的地方）

狼群出沒源、疫病源、礦坑塌方、狩獵受傷、新礦脈發現、遷入者抵達、生育/婚配/死亡判定——這些是「世界的不可預測性」，全部只受參數調製，不受硬編碼控制。
